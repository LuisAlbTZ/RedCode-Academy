# RedCode-Academy
Plataforma educativa para programadores enfocada en resolución de problemas

Es una refactorización de arquitectura y codigo de un programa de Flask-App del repositorio de:

https://github.com/asthasharma98/Flask-Todo-App

Descripción general del proyecto Flask-Todo-App:
Una aplicación web sencilla de tareas pendientes (Todo App) desarrollada con Flask, SQLAlchemy y Bootstrap, y desplegada en Heroku para entender los conceptos básicos del framework Flask.

Versiones Desactualizadas (2026)
Python: 3.8
Flask 1.1
SQLAlchemy 1.4

Caracteristicas principales:
Sencilla: Arquitectura clara e intuitiva que facilita la comprensión y el desarrollo del proyecto.

Ligera: Consumo mínimo de recursos para un rendimiento ágil y eficiente.

Interdependiente: Componentes coordinados que trabajan de forma conjunta y acoplada para el funcionamiento del sistema.

Despliegue Único: Proceso de publicación simplificado al desplegar la aplicación como una sola unidad.

Descripción general del proyecto:
Ingeniería Reversa y Refactorización
Plataforma Educativa desarrollada mediante un enfoque de sistema en capas, cuyo objetivo principal es aprender técnicas avanzadas de desarrollo de software a través de la resolución de problemas.

Objetivo del Proyecto
"Aprender técnicas de desarrollo de software mediante la resolución de problemas"

Aplicamos una reingeniería y la refactorización continua para adaptarla a una plataforma evolutiva manteniendo altos estándares de mantenibilidad.

Arquitectura y Tecnológia
La plataforma está construida utilizando un esquema en capas con las siguientes tecnologías:

Lenguajes: HTML, CSS, JavaScript, Python

Backend: Flask, SQLAlchemy

Frontend: Tailwind CSS

Base de Datos: PostgreSQL

Hosting: Render

Versiones Actualizadas (2026)
Python: 3.12
Flask: 3.1
SQLAlchemy: 2.0

Características Principales:
Escalable: Diseñada para crecer según la demanda de usuarios y recursos.

Soportable: Estructurada para facilitar el mantenimiento y la actualización continua.

Segura: Implementación de buenas prácticas de protección de datos y accesos.

Aislamiento de fallos: Arquitectura modular que evita que errores puntuales comprometan todo el sistema.
